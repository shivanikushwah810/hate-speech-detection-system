Evaluates the real production model files on the held-out test split (about 10–20 seconds). Every run is saved and can be re-opened from the Report menu.

How to read these numbers

  • Accuracy — share of all test texts classified correctly. Can look good even when a rare class is missed, because the classes are imbalanced.
  • Precision — when the model says "Hate Speech", how often is it right? Recall — of all real hate-speech texts, how many did it find?
  • F1-score — one number combining precision and recall. Macro F1 averages the 3 classes equally (best summary when classes are imbalanced). Weighted F1 weights each class by how many texts it has.
  • Confusion matrix — rows are the true labels, columns are the predicted labels. Numbers on the diagonal are correct; everything else is a mistake and shows which classes get confused.
  • Only the local model/pipeline is evaluated. The optional Claude API route is not (it is paid and not deterministic).
